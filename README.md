# reinforcement_learning_four_in_a_row
"Harder, Better, Faster, Stronger" - improve a Python implemented Four in a Row that comes with alternative AI engines like Random Move Selection, Minimax, Alpha-Beta pruning, Negamax and MCTS/UCT by  applying Reinforcement Learning, Zero-Knowledge, Self-Play, Alpha-Zero, Policy Neural Network move selection, PUCT, DQN alike structure.
